# Analog & Digital Electronics Lab (ADE) - SSGMCE

Interactive web dashboard for the **Analog & Digital Electronics Lab** at **Shri Sant Gajanan Maharaj College of Engineering (SSGMCE), Shegaon**.
* **Department:** Information Technology
* **Semester:** III
* **Lab Manual Reference:** `SSGMCE/WI/IT/C008/31T204PC`

## 🚀 Live Demo
Access the live interactive lab portal directly here:
👉 **[https://omingole87.github.io/ade-lab/](https://omingole87.github.io/ade-lab/)**

## ✨ Features
- **Direct Simulation Launch:** One-click launch for Falstad CircuitJS and CircuitVerse simulations.
- **Interactive Lab Tracker:** Tick off completed practicals with persistent progress storage in `localStorage`.
- **Search & Filter:** Search by experiment title, IC numbers (741, 74153, 74155), or filter by Course Outcome (CO1–CO4) and simulator platform.
- **Dark Mode Support:** Light and Dark mode toggle with system preference detection.
- **Print & PDF Ready:** Print stylesheet for saving or printing clean lab index sheets.
